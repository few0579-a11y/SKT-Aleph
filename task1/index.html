02

나의 강점 / 취향

강점 01

관찰력

상황

선거 방송 첫 방영일이라 선배들이 바쁜 상황에서 업무를 파악해야 했다.

행동

직속 선배의 업무를 관찰하며 내가 할 수 있는 일을 판단하고, 필요한 일을 확인한 뒤 함께 처리했다.
자막 적용 상태와 수정 사항도 수시로 확인했다.

결과

자주 사용될 자막 디자인 1개의 미적용을 발견해 방송 송출에 지장이 없도록 했다.
수정 사항은 체크리스트로 정리해 선배가 다음 업무를 진행할 수 있도록 했다.

강점 02

실행력

상황

혼자 공부한 일본어를 실제로 사용하기 위해 일본 워킹홀리데이에서 현지인과 대화했다.

행동

독학한 일본어를 실제 대화에서 사용하고,
모르는 표현은 바로 검색하거나 상대방에게 다시 물어보았다.

결과

공부한 내용을 실제로 사용하는 것에서 기쁨과 성취감을 느꼈으며,
암기할 때 자주 잊었던 단어도 대화에서 사용하면서 더 잘 기억하게 되었다.

취향

지식 연결

상황

웹 개발 과정에서 Oracle 데이터베이스를 처음 배우며
DB와 Java가 어떻게 연결되는지 이해하기 어려웠다.

행동

DBManager라는 Java 파일을 직접 만들고, 다른 Java 파일에서 활용하면서
Oracle 데이터베이스와 Java가 연결되는 과정을 확인했다.

결과

Java와 DB의 연결 구조를 이해하게 되었고,
따로 배운 지식이 서로 연결되어 하나의 구조로 이해되는 과정에서 재미를 느꼈다.
